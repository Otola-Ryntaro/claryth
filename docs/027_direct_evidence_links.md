# 027 相互作用根拠への直接リンク

## 目的
結果カードから検索画面を経由せず、該当相互作用行とPMDA電子添文PDFを開けるようにする。

## 対象外
PDF内のページ番号推定、PMDA文書の再配布、未収載結果への根拠生成。

## 依存
019、020。

## タスク
- [x] PMDA XMLの元ファイル名から電子添文PDF直リンクを生成する
- [x] 相互作用行を即表示するlocalhost根拠ページを追加する
- [x] 結果詳細へ該当行リンクと原資料リンクを表示する
- [x] HTMLエスケープとCSPを適用する
- [x] APIテスト、DBテスト、拡張機能ビルドを追加する

## 受入条件
併用禁忌・併用注意の結果から、該当する薬剤名、臨床症状、機序を1クリックで確認でき、PMDA PDFも検索なしで開ける。
