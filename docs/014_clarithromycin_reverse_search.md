# 014 相手薬側からの逆引き

## 目的
非クラリス文書の10.1・10.2から、クラリスロマイシンを直接記載する相互作用行を抽出する。

## 対象外
「CYP3A阻害剤」だけを根拠とした機序推測の本番アラート化。

## 依存
012、013。

## タスク
- [x] 10.1・10.2の行単位でクラリス関連語を検索する
- [x] ヒット語、薬剤名、効果、機序、相手薬文書を保存する
- [x] クラリス側候補との一致・不一致をレビュー可能にする
- [ ] クラス語のみの候補は別レベルとして将来拡張可能にする

## 受入条件
相手薬側添文に明記されたクラリスロマイシン記載を原文書付きで一覧化できる。

## テスト
直接記載、販売名記載、無関係な本文記載を区別する。
