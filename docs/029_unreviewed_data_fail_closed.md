# 029 未承認データの判定停止

## 目的
医学レビューが完了していないデータセットを、相互作用判定へ使用できないようfail-closedにする。

## 対象外
医学レビュー済みDBの生成と署名。これらは016と031で扱う。

## 依存
016の前提となる安全弁。019、020、021。

## タスク
- [x] 臨床利用可能なレビュー状態を単一の定数で定義する
- [x] トップ20 DBと手動シードのレビュー状態を判定前に検証する
- [x] 未承認時の`POST /v1/check`を503で停止する
- [x] `/health`へ`clinical_ready`と判定対象データを追加する
- [x] サイドパネルに臨床利用禁止を明示し、判定ボタンを無効化する
- [x] 未承認時と承認済み想定時のAPI・DBテストを追加する

## 受入条件
`prototype_manual_review_required`または`pmda_extracted_review_required`のDBでは相互作用結果を返さず、画面上も判定操作ができない。`clinically_reviewed`だけが判定可能である。

## テスト
未承認DBで503になること、承認済み状態を与えたテストDBでは既存のゴールデンケースが維持されること、拡張機能ビルドが成功することを確認する。
