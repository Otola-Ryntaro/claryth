# 022 LLM任意化アーキテクチャ

## 目的
相互作用判定と通常の薬剤名解決をLLMから完全に独立させ、AI補助を任意の名称候補選択だけに限定する。

## 対象外
LLMによる相互作用、重大度、対応、根拠、結果説明の生成。

## 依存
019。

## タスク
- [x] 通常ヘルスチェックからOllama通信を分離する
- [x] DB判定経路からLLM要約を削除する
- [x] LLM停止時もAPI・名称解決・判定が同じ契約で動くようにする
- [x] AI補助の入力と出力を既存薬剤IDへ制限する

## 受入条件
Ollamaを導入していないPCでも、AI補助を除く全機能が利用できる。

## テスト
Ollama関数を失敗させてもhealth、targets、resolve、checkが成功する。
