# 019 トップ20 APIと双方向照合

## 目的
選択した対象薬と入力薬について、双方の電子添文10.1・10.2を直接名称で照合する。

## 対象外
電子添文に薬効群だけで記載された相互作用の自動確定。

## 依存
018。

## タスク
- [x] `GET /v1/targets`を追加する
- [x] PMDA薬剤名マスターを名前解決のフォールバックにする
- [x] `POST /v1/check`へ`target_id`を追加する
- [x] 対象薬側と入力薬側の相互作用行を双方向検索する
- [x] 直接名称がない場合は安全保証でない「記載なし」とする

## 受入条件
対象薬を切り替えると同じ入力薬でも根拠と結果が切り替わる。

## テスト
禁忌、注意、記載なし、未知対象ID、販売名入力を検証する。
