# 020 トップ20対応サイドパネル

## 目的
対象薬を最上部で選択し、その下で併用薬を入力する操作順へ画面を再構成する。

## 対象外
患者情報や検索履歴の保存。

## 依存
019。

## タスク
- [x] 最上部に順位付き対象薬プルダウンを配置する
- [x] その下に複数薬剤入力欄と確認ボタンを配置する
- [x] 結果見出しへ対象薬名を表示する
- [x] 接続状態、起動、LLM操作を画面下部へ移動する
- [x] 小さいサイドパネル幅で操作可能なデザインへ更新する

## 受入条件
初期表示はクラリスロマイシンで、対象薬変更後の判定が一連の操作で完了する。

## テスト
TypeScriptビルド、対象薬取得失敗時、候補選択、結果表示を検証する。
