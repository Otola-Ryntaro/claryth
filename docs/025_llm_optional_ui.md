# 025 LLM任意化UI

## 目的
判定APIだけを標準導線とし、AI補助を明示的に有効化した場合だけOllama操作を表示する。

## 対象外
Ollamaの自動インストール。

## 依存
022、024。

## タスク
- [x] AI補助を初期OFFにする
- [x] 主ボタンを「判定APIを起動」に変更する
- [x] AI補助ON時だけOllama状態、起動、モデル読込を表示する
- [x] Ollama未導入時は通常判定可能と案内する
- [x] AI候補へ「AI候補・要確認」を表示する

## 受入条件
初見利用者がOllamaなしでAPI起動から判定まで完了できる。

## テスト
420px幅、AI OFF/ON、Ollama停止、候補確認を検証する。
