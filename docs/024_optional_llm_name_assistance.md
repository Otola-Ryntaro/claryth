# 024 任意LLM薬剤名補助

## 目的
辞書と通常のあいまい検索で候補が得られない場合だけ、ローカルLLMに低スコア候補の選択を補助させる。

## 対象外
自由記載からの薬剤抽出、DBに存在しない薬剤の生成、相互作用推論。

## 依存
022、023。

## タスク
- [x] AI補助ONかつ未収載の場合だけOllamaを呼ぶ
- [x] 限定シードとPMDA辞書から低スコア候補プールを作る
- [x] LLMへ候補ID・名称だけを渡し、最大3件をJSON Schemaで受け取る
- [x] 未登録ID、不正JSON、タイムアウト、空候補を無視する
- [x] AI候補は必ず要確認とし、利用者の選択前に判定しない

## 受入条件
LLM出力だけで薬剤や相互作用を新規作成できない。

## テスト
未登録ID、不正JSON、タイムアウト、空候補、正常候補を検証する。
