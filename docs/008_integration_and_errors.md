# 008 統合とエラー処理

## 目的
拡張機能とローカルAPIの接続状態、部分失敗、再試行を扱う。

## 対象外
外部クラウドAPIへのフォールバック。

## 依存
006、007。

## タスク
- [x] localhost以外へ通信しないクライアントを実装する
- [x] API停止、DB障害、タイムアウトを利用者向けに表示する
- [x] Ollama状態とデータセット版を表示する
- [x] 再接続操作を実装する
- [x] Windowsユーザー単位の`clarith://`起動ランチャーを実装する
- [x] サイドパネルにAPI・Ollama起動と手動コマンドを追加する

## 受入条件
障害時に医学的な陰性結果として誤表示しない。

## テスト
API停止、Ollama停止、422、500、接続回復を確認する。
