# 018 PMDA汎用相互作用DB

## 目的
PMDA XML全件から薬剤名、販売名、一般名、10.1、10.2、出典文書を保持するローカルSQLiteを構築する。

## 対象外
抽出行の医学的承認と、薬効群記載からの機序推測。

## 依存
017。

## タスク
- [x] 内容重複を除外して全XMLを索引化する
- [x] 一般名・販売名を検索用エンティティと別名へ変換する
- [x] 全文書の10.1・10.2を構造化保存する
- [x] トップ20成分と根拠文書を関連付ける
- [x] データセット日、件数、解析エラーを保存する

## 受入条件
各対象薬から原XML、改訂年月、相互作用行へ遡れる。

## テスト
重複XML、一般名・販売名解決、対象文書同定、改行保持を検証する。
