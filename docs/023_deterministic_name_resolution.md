# 023 決定的な薬剤名解決

## 目的
一般名・販売名・規格付き名称・表記揺れ・軽微な誤字を、辞書とRapidFuzzでLLMなしに処理する。

## 対象外
曖昧候補の自動確定。

## 依存
018、022。

## タスク
- [x] 正規化、限定シード完全一致、PMDA完全一致の順序を固定する
- [x] 限定シードとPMDA別名のあいまい候補を統合する
- [x] 通常閾値以上は候補確認、候補なしは未収載とする
- [x] AI用に通常閾値未満の候補プールを取得できるようにする

## 受入条件
AI補助OFFで一般名・販売名・規格・軽微な誤字を処理できる。

## テスト
全半角、規格、剤形、商品名、一般名、誤字、未知語を検証する。
