- `build_release_bundle.py`はEd25519署名済み固定ZIPと全ファイルmanifestを生成し、未レビューDBからの製品版生成を拒否する。
- 評価版`eval-20260613`を生成し、53ファイル、秘密鍵・`.runtime`・原XML/PDF/CSV混入なしを検証した。サイズとZIP SHA-256はbundle外側の署名manifestへ記録した。
- 公開鍵は配布物と別経路で受領したSHA-256 fingerprintとの一致を確認できる。
- 運用手順、出荷チェックリスト、実機E2E記録票を作成した。
