# 004 薬剤名マスター

## 目的
国内処方薬の一般名・販売名と頻用OTCの商品名・成分を対応付ける。

## 対象外
全OTC品目の初期収載。

## 依存
001、002。

## タスク
- [x] 薬剤、別名、配合成分のテーブルを作成する
- [x] 頻用OTCのサンプルを収載する
- [x] 配合剤を成分単位で評価できるようにする
- [ ] 厚労省マスターから処方薬名を更新する取込処理を追加する
- [ ] OTCカテゴリを段階的に拡張する

## 受入条件
商品名から一意な薬剤または候補一覧へ解決できる。

## テスト
先発名、一般名、規格付き名、OTC配合剤を確認する。
