# 012 PMDA索引DBとスキーマ

## 目的
原文書、ファイルパス、SHA256、改訂年月、販売名、一般名、YJコードを追跡できるSQLiteを構築する。

## 対象外
薬剤名の最終的な標準コード統合。

## 依存
011。

## タスク
- [x] XMLを1回だけ読み込み、SHA256とメタデータを抽出する
- [x] 同一XMLの重複ファイルパスを別テーブルで保持する
- [x] パース失敗を記録して処理を継続する
- [x] データセット件数とビルド時刻をsource_coverageへ保存する

## 受入条件
すべての抽出候補から原XMLとSHA256へ遡れる。

## テスト
重複文書、複数販売名、名前空間付きXML、破損XMLを検証する。
