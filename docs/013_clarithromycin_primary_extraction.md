# 013 クラリス側相互作用抽出

## 目的
クラリスロマイシン含有製剤を同定し、10.1併用禁忌と10.2併用注意を構造化抽出する。

## 対象外
抽出候補の医学的承認と自動的な本番反映。

## 依存
012。

## タスク
- [x] 一般名と有効成分からクラリス含有文書を同定する
- [x] `DrugName`、`ClinSymptomsAndMeasures`、`MechanismAndRiskFactors`を抽出する
- [x] `<?enter?>`を改行として保持する
- [x] severity、section、改訂年月、出典文書を保存する
- [x] 同一内容を集約し、複数文書による裏付け件数を算出する
- [x] 単剤文書を一次候補、クラリス含有配合パックを補足候補として分離する

## 受入条件
クラリス錠200の10.1・10.2表が欠落なく候補DBへ保存され、配合パックの他成分由来相互作用が一次候補へ混入しない。

## テスト
代表XMLの禁忌・注意件数と先頭・末尾レコードをゴールデンテスト化する。
